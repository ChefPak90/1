# EP01-B 제작 패키지 v4 — 「다시 시작할 때, 제가 가진 건 딱 두 개였습니다」

2026-10-05 · 대본: `EP01B_prompter_v4.txt` · 같은 원고로 만든 A안: `EP01_package_v2.md`(「이 말, 하나님이 한 말이 아닙니다」)

## 1. 제목

**확정:** 다시 시작할 때, 제가 가진 건 딱 두 개였습니다 (2026-10-05 박셰프 확정)

- 폐기: 졸업장 하나, 자격증 하나. 제가 처음 세어 본 전부였습니다 — 나열처럼 읽힌다(박셰프 판단).
- 폐기: 「두 개로 다시 시작했습니다」. 결말을 먼저 말해 성공담처럼 읽히고, 누를 이유도 줄어든다.
- 폐기: 「네 시작은 미약하였으나」. 이 안에서는 구절이 주인공이 아니다.
- 채널 이름의 말 「다시 시작」이 제목에 들어가고, 오프닝 20초 안에 육성으로도 나온다(콜드 오픈 첫 문장 · 시그니처).
- 제목은 「가진 건」, 대본은 「내세울 수 있는 건」이다. 4절 "그때 두 개라고 센 건, 제 눈에 보이는 것만 센 거였습니다"가 이 차이를 받는다.
- 상시형이라 연도·"요즘"을 넣지 않는다.

## 2. 썸네일

- **글씨:** 이게 전부였다 (6자, 한 줄) — 제목과 같은 말을 반복하지 않도록 바꿨다(2026-10-05). 사진이 「두 개」를 보여주고, 글씨가 감정을 말하고, 제목이 맥락을 준다. 대본 콜드 오픈의 "그게 전부였어요"와도 맞물린다.
- **구도:** 박셰프 상반신. 옆에 **실물 졸업장과 자격증 두 장**. 실물이 있으면 그 자체가 1차 경험의 증거라 가장 강하다. 없으면 빈 종이 두 장에 손글씨로 「졸업장」「자격증」. 손가락 두 개로 표시하는 구도는 브이(V) 자로 읽히니 쓰지 않는다.
- **색:** 다시시작 팔레트. 샌드베이지 배경, 「전부」만 코랄핑크로 강조.
- **빌린 틀:** 「물건 사진 + 짧은 고백」 구조. 아웃라이어 확인은 아직 안 했다(수요 증거: 약).
- **약속을 지키는가:** 지킨다. 콜드 오픈 첫 문장 "스무 살이 넘어, 다시 시작해야 했을 때, 제가 내세울 수 있는 건 딱 두 개였습니다"(0:00~0:21)에서 졸업장·자격증과 카드 C01이 나온다.

## 3. A안과 무엇이 다른가

| | A안 「하나님이 한 말이 아닙니다」 | B안 「다시 시작할 때, 제가 가진 건 딱 두 개였습니다」 |
|---|---|---|
| 썸네일이 건드리는 것 | 호기심. 익숙한 말의 반전 | 자기 대입. "나는 몇 개지?" |
| 답하는 아픔 | 간접적. 구절 해석을 거쳐 닿는다 | **Pain 1번에 바로 닿는다**("지금까지의 내가 쓸모없게 느껴진다") |
| 오프닝 답 | 0:20 빌닷 | 첫 문장(콜드 오픈) |
| 구절의 자리 | 주인공 | 3절에서 렌즈로만 쓴다(빌닷 이야기는 그대로 둠) |
| 시청자에게 묻는 문장 | 없음 | 오프닝에는 없음(v3). 후반 "그래도 나한테 이건 있지"로 시청자가 떠올리게 함 |
| 분량 | 3,058자 · 촬영 12:33~14:20 | 3,114자 · 촬영 12:46~14:36 |
| 위험 | 신앙 있는 시청자에게 도발로 들릴 수 있음 | 자격증 두 개가 "그래도 있었네"로 들려 공감이 약해질 수 있음. 4절 "그때 두 개라고 센 건 눈에 보이는 것만 센 거였다"로 받음 |

**제 추천은 B안이다.** 채널의 한 문장(「아직 번역되지 않은 자산」)과 Pain 1번에 곧장 닿고, 시청자가 자기 것을 세어 보게 만든다. 첫 편이 채널의 소개 역할도 하므로, 반전보다는 채널이 무엇을 주는지가 바로 보이는 쪽이 낫다. A안의 반전은 쇼츠 1편으로 잘라 쓰면 둘 다 살릴 수 있다(아래 4).

## 4. 쇼츠 후보

1. **「이 말, 하나님이 한 말이 아닙니다」 (약 50초).** 3절 앞부분(구절 → 빌닷 → 조건 → "지금 어디 서 있는지 봐"). A안의 반전을 쇼츠로 살린다.
2. **「졸업장 하나, 자격증 하나」 (약 45초).** 2절 끝(질문이 바뀐 순간 → 세어 본 두 개 → 출발점이 보였다).
3. **「폐식용유 계약 50불」 (약 40초).** 4절(주방 23년이 대화의 시작이 된 장면).
