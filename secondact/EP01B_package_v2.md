# EP01-B 제작 패키지 v2 — 「내가 가진 건 딱 두 개였다」

2026-10-05 · 대본: `EP01B_prompter_v2.txt` · 같은 원고로 만든 A안: `EP01_package_v2.md`(「이 말, 하나님이 한 말이 아닙니다」)

## 1. 제목

**확정안(초안):** 졸업장 하나, 자격증 하나. 제가 처음 세어 본 전부였습니다

- 폐기: 「두 개로 다시 시작했습니다」. 결말을 먼저 말해 성공담처럼 읽히고, 누를 이유도 줄어든다.
- 폐기: 「네 시작은 미약하였으나」. 이 안에서는 구절이 주인공이 아니다.
- 상시형이라 연도·"요즘"을 넣지 않는다.

## 2. 썸네일

- **큰 글씨:** 딱 두 개였다 (6자)
- **보조 문구:** 내가 가진 건
- **구도:** 박셰프 상반신. 옆에 **실물 졸업장과 자격증 두 장**이 놓인 사진을 둔다. 실물이 있으면 그 자체가 1차 경험의 증거라 가장 강하다. 없으면 빈 종이 두 장에 손글씨로 「졸업장」「자격증」. 손가락 두 개로 표시하는 구도는 브이(V) 자로 읽히니 쓰지 않는다.
- **색:** 다시시작 팔레트. 샌드베이지 배경, "두 개"만 코랄핑크로 강조.
- **빌린 틀:** 「숫자 + 고백」 구조("내가 가진 건 ○○뿐이었다"). 아웃라이어 확인은 아직 안 했다(수요 증거: 약).
- **약속을 지키는가:** 지킨다. 0:10 무렵 "졸업장 하나, 자격증 하나"를 바로 말하고 카드 C01이 뜬다.

## 3. A안과 무엇이 다른가

| | A안 「하나님이 한 말이 아닙니다」 | B안 「딱 두 개였다」 |
|---|---|---|
| 썸네일이 건드리는 것 | 호기심. 익숙한 말의 반전 | 자기 대입. "나는 몇 개지?" |
| 답하는 아픔 | 간접적. 구절 해석을 거쳐 닿는다 | **Pain 1번에 바로 닿는다**("지금까지의 내가 쓸모없게 느껴진다") |
| 오프닝 답 | 0:20 빌닷 | 0:10 졸업장·자격증 |
| 구절의 자리 | 주인공 | 3절에서 렌즈로만 쓴다(빌닷 이야기는 그대로 둠) |
| 시청자에게 묻는 문장 | 없음 | 오프닝에서 "여러분은 지금 손에 있는 걸 세어 보신 적 있으세요?" |
| 분량 | 3,058자 · 촬영 12:33~14:20 | 3,012자 · 촬영 12:21~14:07 |
| 위험 | 신앙 있는 시청자에게 도발로 들릴 수 있음 | 자격증 두 개가 "그래도 있었네"로 들려 공감이 약해질 수 있음. 4절 "그때 두 개라고 센 건 눈에 보이는 것만 센 거였다"로 받음 |

**제 추천은 B안이다.** 채널의 한 문장(「아직 번역되지 않은 자산」)과 Pain 1번에 곧장 닿고, 시청자가 자기 것을 세어 보게 만든다. 첫 편이 채널의 소개 역할도 하므로, 반전보다는 채널이 무엇을 주는지가 바로 보이는 쪽이 낫다. A안의 반전은 쇼츠 1편으로 잘라 쓰면 둘 다 살릴 수 있다(아래 4).

## 4. 쇼츠 후보

1. **「이 말, 하나님이 한 말이 아닙니다」 (약 50초).** 3절 앞부분(구절 → 빌닷 → 조건 → "지금 어디 서 있는지 봐"). A안의 반전을 쇼츠로 살린다.
2. **「졸업장 하나, 자격증 하나」 (약 45초).** 2절 끝(질문이 바뀐 순간 → 세어 본 두 개 → 출발점이 보였다).
3. **「폐식용유 계약 50불」 (약 40초).** 4절(주방 23년이 대화의 시작이 된 장면).
